# Cultural Highlights

A cultural web platform covering the history and culture of five countries — Ukraine, Romania, Ireland, China, and India. Built as part of coursework at Dublin City University over a 5-week sprint.

🔗 **Live site:** [cultural-highlights.netlify.app](https://cultural-highlights.netlify.app)

## About

This project explores the history, traditions, and culture of five countries through a responsive, multi-page website, built collaboratively by a team of 5 students.

## Features

- 10+ responsive pages covering five countries' history and culture
- Consistent navigation and layout across all sections

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Deployment:** Netlify
